Next-Gen Edge Security.

Vision OS is a Python-based edge-AI CCTV appliance featuring facial recognition, high-throughput ALPR, multi-threaded pipelines, and dynamic alert queues.

View Repository

Enterprise-Grade Features

👥

Visitor Auto-Identity

InsightFace-powered facial recognition. Automatically distinguishes enrolled employees from recurring visitors, assigning unique auto-IDs and logging them instantly.

🚗

High-Throughput ALPR

Dedicated Centroid Trackers for vehicles with throttled OCR, OpenCV DNN Super Resolution (FSRCNN), and regex-based plate validation for toll-gate speeds.

⚡

Multithreaded Pipeline

A robust Producer-Consumer architecture using thread-safe queues. Heavy disk I/O and capture latency never blocks the main AI inference loop.

🔒

Secure MQTT Alerts

Enterprise cellular-based alerting architecture featuring TLS encryption, password auth, and SQLite-backed store-and-forward queueing.

📊

Live Streamlit UI

A dynamic local dashboard providing real-time views of live monitoring, smart attendance logs, system storage, and instantaneous visitor alerts.

🦺

Industrial Compliance

Configurable attribute extractors capable of verifying PPE compliance (e.g., checking for high-visibility vest colors in restricted hazard zones).

Powered by modern computer vision
